ComfyChair brings the power of ComfyUI to your Android device with a native Material 3 Expressive interface. Connect to your ComfyUI server and generate AI images and videos right from your phone.

What you can do:
- Generate images from text prompts with live progress updates
- Transform existing images or use inpainting with a built-in mask editor
- Create AI videos from text or animate still images
- Follow your jobs in the queue, cancel them, move them to the front, or clear the queue
- Browse all your creations in the gallery, with Undo for every deletion
- Work offline with cached data when your server is unavailable (with media stored on the device)

Flexible workflow support:
- Works with both traditional Checkpoint and modern UNET workflows (Flux, Z-Image, and more)
- Stack up to 5 LoRAs with individual strength controls
- Create new workflows from scratch or import existing ones from ComfyUI
- Full node graph visualization and editing with a searchable node browser, and an overview of large graphs when zoomed out
- Organize nodes into groups and add notes with Markdown support

Built for mobile:
- Image, Video, Gallery and Settings tabs with predictive back
- A full-screen prompt editor and one-tap parameter chips
- Manage multiple servers with per-server settings
- HTTP Basic Auth, API key and browser SSO sign-in for secured servers
- Private by default: generated media stays in memory, no analytics, no cloud backup
- Pinch-to-zoom media viewer with swipe navigation
- Batch operations for saving, sharing, or deleting multiple items
- Backup and restore your configuration across devices
- Available in English, German, French, Polish, Spanish, and Chinese

Requirements:
- A running ComfyUI server (local or remote)
- Android 13 or higher

ComfyChair is free, open source (GPL-3.0), and not affiliated with the official ComfyUI project.
